## Forbidden Words — General (never appear in student-facing copy)

leverage, unlock, crush it, easy, simply, just, fail, wrong, incorrect,
optimize, seamless, robust, innovative

**Special handling:**
- "wrong" and "incorrect" are forbidden in feedback blocks specifically.
  They may appear in academic or geographic context ("wrong side of the
  border", "incorrect map projection for this use case") if the usage
  is clearly not evaluative. Flag and note — let Rob decide.
- "just" is forbidden as a minimizer ("just enter your answer",
  "it's just a matter of..."). Acceptable in other uses ("just as
  important", "just as the map shows"). Use judgment.

## Forbidden VARK / Identity Language

Never appears anywhere in student-facing copy:

- "you're a visual learner" (or any learning type label)
- "you're weak at"
- "you struggle with" — when used as a pattern characterization
  (acceptable in-the-moment: "this is a tricky one")
- "your learning style"
- "this format is hard for you"
- "you consistently get wrong"
- "you failed to"

## Wrong-Answer Feedback Rules

Feedback blocks appear when a student selects a wrong-answer distractor.

**Never:**
- Say "wrong" or "incorrect"
- Open with false positivity: "Almost!", "Good try!", "So close!"
- Restate the correct answer without identifying the misconception
- End without redirecting somewhere (a pattern, a concept, a direction)

**Always:**
- Name the specific thinking error the distractor reveals
- Redirect to reasoning or evidence
- Stay neutral in tone — not punishing, not cheerful

**Misconception test:**
Could this feedback block appear on a different question and still make
sense? If yes, it's too generic. A good feedback block is specific enough
that it could only belong to this distractor on this question.

## Sentence Rhythm — 9th Grade (pilot grade band)

- Default pattern: short setup → medium explanation → short landing
- Em dashes: yes — used to extend a thought naturally
- Contractions: yes — "you're", "it's", "don't" keep voice human
- Fragments: acceptable sparingly for emphasis ("That's mastery.")
- Exclamation points: one per screen maximum; genuine milestone only

## Pre-Apology Rule

Never pre-apologize for difficulty:
- "This next part gets complicated" → cut
- "Don't worry if this seems hard" → cut
- "This is a tricky concept, but..." → cut

Naming difficulty directly is fine:
- "This is a tricky one." → keep
- "Notice what makes this harder than it looks." → keep

---

## False Stakes Rule

Never:
- "This will be on the test!"
- "You'll need this for the exam."
- "Pay close attention — this is important for your grade."

---

## Wonder Hook Rule

A wonder hook is NOT:
- A definition: "A map projection is a method of..."
- A statement of objectives: "In this module, you will learn..."
- A summary: "France is a country in Western Europe with..."

A wonder hook IS:
- A contradiction: two true things that seem to conflict
- Real stakes: a consequence that matters without being false drama
- A visible mystery: something observable that demands explanation

Hook must create curiosity before any concept is named.

## Big Idea Callback Rules

**Passive instance (Folio answers, mid-module):**
- Must reframe the concept as an insight, not a definition
- Must not open with "In this module, we learned..."
- Must feel like a teacher stepping back and saying "here's the real point"

**Active instance (EIB prompt, student answers):**
- Must not have a single correct answer
- Must require reasoning, not recall
- Must include a scenario that grounds the reasoning task
- "There's no single right answer. The reasoning is the evidence."
  → This closing line (or equivalent) should be present.
