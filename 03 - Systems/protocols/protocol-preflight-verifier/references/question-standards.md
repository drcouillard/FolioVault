# Question Standards Reference
## Authority for Checklist C — Question and Question Set Standards

Load this file when running preflight on a single question or question set.

---

## Required Fields — Every Question

| Field | Required | Notes |
|---|---|---|
| Question stem | Yes | Clear, unambiguous, one defensible correct answer |
| Four options (A–D) | Yes | Exactly four; no "all of the above", "none of the above" |
| Correct answer marked | Yes | Single letter |
| Bloom level tag | Yes | Apply or above; Remember/Understand not permitted |
| Spiral tag | Yes | [NEW: concept] or [SPIRAL: module — concept] |
| Difficulty level | Yes | Foundational / Standard / Challenge / Transfer |
| Diagnostic feedback blocks | Yes | Exactly three (one per wrong-answer distractor) |

---

## Bloom Level Floor

Folio questions operate at Apply level or above. Always.

| Level | Permitted | Notes |
|---|---|---|
| Remember | No | Tests recall only — not a Folio question |
| Understand | No | Tests comprehension only — not a Folio question |
| Apply | Yes | Minimum floor — use in context, not just define |
| Analyze | Yes | Break down, distinguish, compare |
| Evaluate | Yes | Judge, defend, critique with evidence |
| Create | Yes | Rare — synthesis tasks |

If a question stem asks a student to name, define, list, or identify
without applying the concept, it is likely Remember or Understand.
Flag it.

---

## Difficulty Level Definitions

| Level | Definition | Bloom range | Notes |
|---|---|---|---|
| Foundational | First application; concept is new or recently introduced | Apply | Maximum scaffolding available |
| Standard | Concept has been seen before; application in new context | Apply–Analyze | Moderate scaffolding |
| Challenge | Multi-concept; requires integration or comparison | Analyze–Evaluate | Minimal scaffolding |
| Transfer | Novel context; student must reason without direct parallel | Evaluate–Create | No scaffolding |

Every question set should include questions across at least two difficulty levels.
A set of all Foundational questions is a flag.

## Feedback Block Standards

### Structure
Each feedback block addresses one specific wrong-answer distractor.
A question with four options has three wrong answers = three feedback blocks.

### Required elements per block
1. **Misconception identification** — name the specific thinking error
2. **Redirection** — point toward reasoning, evidence, or a pattern to notice
3. **No verdict language** — never say "wrong", "incorrect", "that's not right"

### Misconception test
Ask: could this feedback block appear on a different question and still
make sense? If yes, it is too generic. A valid feedback block is specific
to this distractor on this question.

**Too generic (flag):**
"That's not quite right. Think about the relationship between climate
and geography and try again."

**Specific enough (pass):**
"Alsace sits on France's northeastern border with Germany and has a
semi-continental climate — colder winters, warmer summers, but not the
dry Mediterranean pattern. Notice the pattern: distance from the Atlantic
and Mediterranean shapes the climate, not just latitude."

### Opening moves — permitted
- Name where the distractor's reasoning breaks down
- Acknowledge what is true in the wrong answer before redirecting
- Ask a redirecting question ("Notice the pattern: ...")
- Reference a concept from a prior module if relevant

### Opening moves — forbidden
- "Almost!" / "So close!" / "Good try!"
- "That's wrong." / "Incorrect."
- Restating the correct answer without explaining the misconception
- Generic encouragement without content

## Spiral Tag Format

Every question must carry exactly one spiral tag.

**New concept question:**
`[NEW: France — Physical/Climate]`
Format: [NEW: Module — Concept Area]

**Spiral question:**
`[SPIRAL: Human Geo — Urbanization]`
Format: [SPIRAL: Source Module — Concept Area]

Source module must be a completed module in the student's history.
No phantom spiraling — a concept cannot be tagged as spiral if the
student hasn't completed its source module.

## Question Stem Standards

A valid question stem:
- Has one clearly correct answer
- Does not contain the answer within the stem
- Is answerable from the content of the module (no outside knowledge required
  beyond what would be reasonable for a 9th-grade student)
- Does not use trick wording, double negatives, or "which of the following
  is NOT true" constructions (flag these — they test test-taking skill,
  not geographic reasoning)
- Grounds the question in a real-world context where possible
  (the "real-geography rule" — no fictional places or fabricated scenarios)

## Set-Level Standards (question set only)

| Check | Requirement |
|---|---|
| Bloom distribution | At least one Apply and one Analyze in every set |
| Difficulty distribution | At least two difficulty levels represented |
| Spiral ratio | Actual new/prior count matches declared metadata ratio |
| Mastery threshold | Defined for the set (expressed as n/total) |
| No duplicate concepts | Two questions should not test the same concept in the same way |
