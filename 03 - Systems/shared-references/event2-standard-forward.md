## "Before the Questions" Block
*Applies to all Folio module specs from GEO-MS-004 forward.*
*Retrofit patches for GEO-MS-001/002/003 in: updated-specs/*

---

## Placement

Between the Worked Example (Section 8) and the Practice Set (Section 9).
Not a numbered section. A visual break with a short heading and four bullets.

---

## Format

```
**Before the Questions**

Here's what this module covers:

- [Sub-objective 1 — stated as content covered, not as a student outcome]
- [Sub-objective 2]
- [Sub-objective 3]
- [Sub-objective 4 — four bullets maximum; combine if module has more]
```

---

## Voice Rules

- Present tense, declarative: "Scale is a ratio" not "You will understand scale as a ratio"
- No "by the end of this module" — that's syllabus language
- No "you will be able to" — that's compliance language
- Reads like a navigator's checklist: here's what we covered, here's where we are
- Four bullets maximum — if a module has more than four sub-objectives,
  combine the most closely related pair into one bullet
