# Scaffold Tier Definitions
## Folio Interactive — Reference File
*Applies to all modules. Shared reference — do not modify per-module.*

---

## Purpose

Every practice question in Folio has three scaffold tiers available to
students who request a hint. This file defines what each tier does, what
it sounds like, and what it must not do. Load this file before writing
any hint progressions.

---

## The Three Tiers

### Tier 1 — Redirect

**What it does:** Points the student toward the relevant concept section
without narrowing the answer space.

**What it must not do:** Give away the answer. Eliminate any distractors.
Signal which option is correct.

**Tone:** Calm. Directional. Like a teacher pointing at a page: "Start here."

**Format:**
> "Take another look at [the relevant concept or section]. The key idea
>  for this question is [concept name — not the answer]."

**Example:**
> "Take another look at the section on map selection. The key idea for
>  this question is what a mapmaker decides to include — and why."

---

### Tier 2 — Narrow

**What it does:** Reduces the reasoning space. May eliminate one or two
clearly wrong paths by explaining why those paths don't apply — but does
not identify the correct answer.

**What it must not do:** Point directly at the correct answer. Say
"the answer is not A or B, so it must be..." (that's giving the answer).

**Tone:** Slightly more engaged. Collegial. Like a teacher leaning in:
"Let's think about this differently."

**Format:**
> "Here's something to consider: [reframe the question around the
>  operative variable]. Think about what [X] means for [the task in
>  the question] — not what it means in general."

**Example:**
> "Here's something to consider: this question is about a specific
>  purpose — tourism navigation. Think about what a tourist actually
>  needs to do with a map, and what would make a map useful or useless
>  for that task specifically."

---

### Tier 3 — Isolate

**What it does:** Restates the question with the core variable isolated.
Makes the decision point explicit without supplying the answer.

**What it must not do:** Answer the question. This tier should feel like
the last step before the student answers independently.

**Tone:** Direct. Clean. No hedging. Like a teacher who's done hinting
and is now asking the student to commit: "Here's exactly what you're
deciding."

**Format:**
> "The decision here is: [restate the exact choice the question is
>  asking the student to make, stripped of context]. Which option
>  matches that?"

**Example:**
> "The decision here is: does a tourist need to know rainfall data
>  to navigate a national park? Which option matches that?"

---

## Tier Sequencing Rules

- Tiers are presented in order: 1 → 2 → 3. Students cannot skip to Tier 3.
- Each tier is only displayed after the student requests it.
- After Tier 3 is displayed, no further hints are available.
- After viewing any hint tier, the student can still answer the question
  — hints do not lock out the attempt.
- Hint usage is tracked as metadata (for mastery inference and instructor
  view) but is not displayed to the student as a score penalty.

---

## Remediation Scaffold Language

When a student is routed to remediation (score below mastery threshold),
the routing message must follow this pattern:

**Never:**
- "You didn't pass. Let's review."
- "You got [X] wrong. Here's what you missed."
- "You need more practice before moving on."

**Always:**
> "Let's look more closely at [concept area]. A few of the questions
>  in this set touched on [concept] — here's another angle on it
>  before you try again."

Then: re-present the relevant concept section or worked example at higher
scaffold (more broken-down steps, more explicit structure), followed by
a retry of the specific concept area — not the full module.

## Self-Check Before Submitting Hint Copy

- [ ] Tier 1 does not narrow the answer space
- [ ] Tier 2 does not identify the correct option
- [ ] Tier 3 does not give the answer — isolates the decision only
- [ ] All tiers use plain language — no jargon without definition
- [ ] Remediation routing copy uses "let's look more closely at" framing
- [ ] No avoid-list words appear in any tier
