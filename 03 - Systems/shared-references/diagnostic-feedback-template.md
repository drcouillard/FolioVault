# Diagnostic Feedback Template
## Folio Interactive — Reference File
*Applies to all modules. Shared reference — do not modify per-module.*

---

## Purpose

Every wrong-answer distractor in every Folio practice question requires a
diagnostic feedback block. This file defines the format, the rules, and
the self-check. Load this file before writing any feedback copy.

---

## What Diagnostic Feedback Is

Diagnostic feedback tells a student what their wrong answer reveals about
their thinking — and redirects them toward the reasoning, not the answer.

It is not:
- A restatement of the correct answer
- A generic encouragement ("Good try! Here's the right answer...")
- A penalty ("That's incorrect. The answer is...")
- A hint toward the answer ("Think about what we said about X...")

It is:
- A name for the misconception the wrong answer reveals
- A redirect toward the reasoning process that resolves it
- A cue — a question or direction that points toward the concept, not the answer

---

## Format

```
DIAGNOSTIC FEEDBACK
────────────────────
Question:       [full question stem]
Wrong answer:   [the specific distractor this block addresses]
Misconception:  [one sentence — what this answer reveals about the student's
                 understanding. Be precise. Not "they didn't know X" but
                 "this answer treats X as Y, which misidentifies the relationship"]
Feedback:       [3 sentences maximum]
                Sentence 1: Name what the wrong answer assumes or conflates.
                Sentence 2: Redirect to the reasoning process or the relevant
                            concept — never to the answer.
                Sentence 3: Close with a cue — a question or direction that
                            activates thinking. Never a destination.
```

One block per distractor. A 4-option MCQ generates 3 blocks (one per wrong answer).

---

## Voice Rules for Feedback Copy

From `folio-voice.md` — apply every time:

**Never use:**
- "wrong" / "incorrect" / "that's not right"
- "almost!" / "so close!" / "nice try!"
- "the answer is..." / "you should have..."
- "fail" / "easy" / "simply" / "just"

**Always:**
- Name the misconception specifically — not "you misunderstood X" but
  what specifically the wrong answer assumes
- Redirect to reasoning — point toward the concept mechanism, not the fact
- Close with a question or direction that activates thinking
- Neutral tone — not warm, not cold; diagnostic, like a teacher reviewing
  a test paper with a student

---

## Sentence Templates (Use as Starting Points — Not Verbatim)

**Sentence 1 — Naming the misconception:**
- "This answer assumes [X], but [X] is actually [correct relationship]."
- "[Option chosen] treats [A] and [B] as equivalent — they're related but not the same."
- "This is a reasonable inference if [X condition] — but the question specifies [Y condition]."
- "This confuses [A] with [B] — they operate at different [levels / scales / functions]."

**Sentence 2 — Redirecting to reasoning:**
- "Go back to [the relevant concept] — the key variable here is [Z], not [W]."
- "The distinction that matters: [concept A] affects [outcome], while [concept B] affects [different outcome]."
- "Think about what the question is actually asking: [reframe the question without giving the answer]."
- "Look at [the specific element of the question] — what does that tell you about [the variable]?"

**Sentence 3 — Cue (question or direction, never the answer):**
- "What would change if [variable] were different?"
- "Which part of the question gives you the constraint that rules this out?"
- "If [wrong answer] were correct, what would that imply about [related concept]?"
- "Read [the relevant part of the question stem] again — what's the actual task?"

---

## Self-Check Before Submitting Feedback Copy

- [ ] Misconception is named specifically — not vaguely
- [ ] No avoid-list words appear anywhere
- [ ] Sentence 3 is a cue, not a destination — it activates thinking, not answering
- [ ] Feedback is 3 sentences or fewer
- [ ] Tone is neutral-diagnostic — not cheerful, not cold
- [ ] The correct answer is never stated or strongly implied

## Example — Approved Format

**Question:** A map has a scale of 1:500,000. What does this mean?
**Wrong answer:** A) The map is 500,000 times larger than the area it shows.

```
DIAGNOSTIC FEEDBACK
────────────────────
Question:       A map has a scale of 1:500,000. What does this mean?
Wrong answer:   The map is 500,000 times larger than the area it shows.
Misconception:  This answer reverses the scale relationship — it treats the
                map as larger than reality, when scale ratios always express
                reality as larger than the map.
Feedback:       Scale ratios are always written as map distance first, real-world
                distance second — so 1:500,000 means one unit on the map equals
                500,000 units on the ground, not the other way around. The real
                world is always larger than the map that represents it. What
                would it mean physically if a map were 500,000 times larger than
                the territory it showed?
```
