## How Spiral Tags Work in Folio

Every practice question carries exactly one tag:

- `[NEW]` — concept introduced in this module
- `[SPIRAL: MODULE-ID — concept area]` — concept from a prior module

Tags are internal metadata. Students do not see them.
Tags are used by the adaptive system to track concept coverage and
select prior concepts for future modules' practice sets.

**Bloom level escalation rule:**
The first time a concept appears as a spiral question, it appears at
the same Bloom level as its original introduction. On subsequent spiral
appearances (in later modules), the Bloom level escalates. GEO-MS-002
is the first spiral appearance for GEO-MS-001 concepts — so they appear
at Understand / Apply, matching GEO-MS-001's target level.

## For Future Modules

When GEO-MS-003 and beyond are built, this reference file pattern
is replicated for each module. Each module's spiral tag reference
lists all eligible prior concepts from all completed modules at the
time that module is reached.

For modules after GEO-MS-002, the eligible list expands to include:
- All GEO-MS-001 concepts (at escalated Bloom level)
- All GEO-MS-002 concepts (at introduction Bloom level)
- And so on.

The folio-spiral-calculator skill handles the ratio calculation
(how many spiral vs. new questions per set). This file handles
the tagging reference only.
