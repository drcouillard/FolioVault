**Enduring Understanding:**
Spatial thinking is not a single skill — it is the practiced ability to
recognize which tools apply to a geographic problem and how to use them
in combination. Every Chapter 1 tool is partial on its own. The
geographic reasoner is the one who notices what a problem requires,
selects the right tools, and uses them in concert.

**Scope boundary:**
This module does not introduce new tools. It only introduces "spatial
thinking" as a named metacognitive concept. Every other concept in the
practice set is a spiral revisit. Do not develop new tool content here.
Do not extend Chapter 1 concepts beyond what was established in
GEO-MS-001 through GEO-MS-006. The capstone synthesizes — it does not
expand.

**Chapter 1 completion gate:**
Passing this module clears Chapter 1 and unlocks Chapter 2 (Climate &
Weather Systems). All Chapter 1 tools transfer forward as background
knowledge.

### 3. Diagnostic Feedback Blocks

One block per wrong-answer distractor. Format and rules:
`references/diagnostic-feedback-template.md`

**Special notes for capstone feedback:**
- All feedback must reinforce the spatial thinking habit — name the
  reasoning move the student missed, not just the wrong answer
- Q1 feedback must hold the distinction between tool competence and
  spatial thinking — do not collapse them
- Q7, Q9, Q10 (Evaluate level) feedback must respect that these are
  judgment questions — multiple defensible answers may exist; feedback
  identifies which reasoning was incomplete, not which answer was "wrong"
- Feedback must never disparage tool use — the issue is always
  combination and selection, not the tools themselves

### 4. Hint Progressions

Three scaffold tiers per question. Tier definitions:
`references/scaffold-tier-definitions.md`

**Special notes for capstone hints:**
- Tier 1 (always): Return student to the relevant prior module's
  concept explainer section — not to a re-explanation embedded here
- Tier 2: Name which tools the question is asking the student to combine,
  without resolving the combination
- Tier 3: Walk through the reasoning chain partially, leaving the final
  judgment to the student

### 5. Gagné Event 2 — "Before the Questions" Block

Placed after the worked example, before the practice set.
Format standard: `references/event2-standard.md`

Approved text:
- Spatial thinking starts with a question: what does this problem
  actually require me to know — and which tools apply?
- Every Chapter 1 tool is partial on its own — coordinates need
  projections; legends need map types; directions need references
- The most important reasoning happens in tool combinations, not in
  any single tool used in isolation
- The capstone evidence is not a single answer — it's a defensible
  chain of reasoning that uses the right tools in the right order

### 6. Big Idea Callback — Three-Scenario EIB

Passive (mid-module): approved text in spec Section 5.
Active (EIB): three-scenario student choice — Expedition / Urban /
Disaster Response. Same rubric across all three. Approved text and
rubric in spec Section 10.

EIB rubric: 12 points · mastery 9/12. Six criteria:
- Map type selection (3 pts)
- Scale reasoning (2 pts)
- Projection reasoning (2 pts)
- Coordinates + direction integration (2 pts)
- Legend / map-as-argument insight (2 pts)
- Reasoning coherence (1 pt)

- **Q7, Q9, Q10 (Evaluate level):** First Evaluate-level questions in
  Chapter 1. Confirm grade-appropriateness with educator verifier. All
  three are intentionally at the Chapter 1 ceiling.
- **EIB three-scenario design:** First Folio EIB with student choice
  among three scenarios. Confirm rubric calibrates fairly across
  scenarios — the same rubric must be reasonably scorable for all three.
- **Spatial Reasoning Lab artifact:** Most complex artifact in Chapter
  1. Scenario library, state machine, and tutorial mode all require
  separate scoping and educator verification before build.
- **Q8 ESE direction:** Question references east-southeast (a secondary
  intermediate direction). This was introduced in GEO-MS-006 Going
  Deeper. Confirm appropriate carryover at 9th grade level.
- **Worked example geography:** Greenland search-and-rescue scenario
  uses Polar Stereographic projection. Confirm this is standard for the
  context and that the projection reasoning is accurate.
- **All [VERIFY] tags** in spec require fact-checking before Beta.
- **Chapter 1 completion language:** This is the first place "Chapter 1
  complete" appears. Future module specs should not use this language
  — it is reserved for capstones.
