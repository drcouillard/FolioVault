# Copy Contexts — Blueprint

Used in Step 6 of brand-voice-system. Load when defining copy rules by content type.

---

## Purpose

Same voice, different rules. This file defines how the brand voice behaves across each content context. Every context has its own job — the rules here make sure the voice stays consistent while the format serves the function.

---

## Context Definitions

### 1. Website Headline / Hero Copy

**Job:** Stop the scroll. State the brand's primary value immediately. Set the emotional tone for everything that follows.

**Rules to define:**
- Character count target (most heroes: 6–12 words; never more than 20)
- Does the headline lead with outcome, emotion, or differentiation?
- Is there a subhead? What's its job relative to the headline?
- CTA button language: action verb + outcome (e.g., "Start building" not "Submit")
- What the headline must never do (e.g., "never use a question as a headline" or "never open with 'we'")

**Format to document:**
```
Hero Headline: [Length] words. Leads with [outcome / emotion / differentiation].
Subhead: [Yes/No]. Job: [One sentence on its role].
CTA: Action verb + [short outcome]. Example: "[Sample CTA]"
Never: [Specific prohibitions]
```

---

### 2. Product Descriptions

**Job:** Convince a ready buyer. Not the place to introduce the brand — that's already done. This is where features become benefits and benefits become decisions.

**Rules to define:**
- Lead with: benefit or feature? (Most brands: benefit first, feature second)
- Length: short (1–2 sentences) / medium (3–5 sentences) / long (full paragraph+)
- What must always be included (e.g., key differentiator, material, use case)
- What must never appear (jargon, competitor names, unsubstantiated claims)
- Tone shift allowed? (e.g., more precise/utilitarian than brand default)

**Format to document:**
```
Lead with: [Benefit / Feature / Emotional hook]
Length: [Short / Medium / Long] — [sentence target]
Always include: [...]
Never include: [...]
Tone note: [Any context-specific shift from baseline]
```

---

### 3. Marketing / Ad Copy

**Job:** Create desire or urgency in a cold or warm audience. Shorter windows, higher stakes than organic content.

**Rules to define:**
- Hook style: question / bold statement / pain point / aspiration
- Body length: how many lines before CTA
- CTA style: soft ("learn more") or direct ("get yours") — brand decides
- Emotional lever: does this brand use fear, aspiration, humor, or belonging?
- What the brand never does in ads (e.g., "we never use countdown timers" or "we never use comparison claims")

**Format to document:**
```
Hook style: [Question / Statement / Pain / Aspiration]
Body: [X] lines max before CTA
CTA: [Soft / Direct] — example: "[Sample CTA]"
Emotional lever: [Primary emotion used]
Never: [Prohibitions]
```

---

### 4. Email Subject Lines

**Job:** Get the open. One shot, one chance.

**Rules to define:**
- Character count target (mobile preview is ~40 chars; desktop ~60)
- Personalization: use first name or not? In subject or preview text?
- Format preference: question / statement / teaser / directive
- Emoji: yes, no, or sometimes (if yes, define where — subject vs. preview)
- What always gets opens for this brand's audience (curiosity, urgency, exclusivity, value)
- What to never do (all caps, clickbait, misleading subject lines)

**Format to document:**
```
Length: [X] characters max
Personalization: [Yes / No / Preview text only]
Format: [Question / Statement / Teaser / Directive]
Emoji: [Yes / No / Occasionally] — [placement rule]
High-open triggers: [...]
Never: [Prohibitions]
```

---

### 5. Social Posts

**Job:** Earn attention in a noisy feed. Different platforms have different norms — the brand voice stays consistent, the format adapts.

**Rules to define (per platform if applicable):**
- Hashtag policy: how many, where (end of post or inline)
- Tagging: do we tag other brands? People? Events?
- Post length default by platform
- Tone adjustment from baseline (most brands: +1 casual on social)
- What types of content this brand does and does not post (e.g., "we don't do trending audio unless it's genuinely on-brand")

**Format to document:**
```
[Platform] — [Length target] — [Tone shift from baseline]
Hashtags: [X] max — [placement]
Tone note: [...]
Content types: Do: [...] Don't: [...]
```

---

### 6. Error Messages / UI Copy

**Job:** Reduce friction and maintain trust at the moment things go wrong. This is the hardest context — brands often go robotic or overly apologetic here.

**Rules to define:**
- Tone: never cold, never robotic, never falsely cheerful
- Apology policy: does this brand apologize? How? (e.g., "brief acknowledgment, not excessive")
- Resolution focus: always pivot to "here's what to do next" within the same message
- What brands in this category typically do wrong (so this brand avoids it)
- Sample phrasing: 1 good error message and 1 bad one

**Format to document:**
```
Tone: [Adjustment from baseline]
Apology: [Yes, brief / No / Acknowledge + move on]
Always include: Clear next step
Sample good: "[Example]"
Sample bad: "[Counter-example]"
```

---

### 7. Presentations / Decks

**Job:** Support a speaker or stand alone as a document. Different from all other copy contexts — more structured, more visual, less prose.

**Rules to define:**
- Slide headline style: complete sentence or fragment?
- Bullet point policy: full sentences or fragments? How many per slide?
- When to use body copy vs. visual-only slides
- Level of formality vs. brand baseline (often +1 formal for decks)
- What this brand never does in decks (e.g., "never use 'synergy' or 'leverage'" or "never put a paragraph on a slide")

**Format to document:**
```
Headline style: [Complete sentence / Fragment / Both]
Bullets: [Full sentences / Fragments] — [X] max per slide
Body copy: [When it appears and when it doesn't]
Tone: [Shift from baseline, if any]
Never: [Deck-specific prohibitions]
```
