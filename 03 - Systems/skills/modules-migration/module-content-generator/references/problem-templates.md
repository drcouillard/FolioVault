# Problem Templates

Templates for practice problems and mini-quizzes. Follow the structure exactly.
Slot in content from the verified domain expert output; do not substitute values or formulas from memory.

---

## Standard Practice Problem (FE / PE)

```
[TOPIC LABEL] | [EXAM LEVEL] | [DISCIPLINE] | [DIFFICULTY TIER]

---

PROBLEM

[2–4 sentence scenario setup. Name the system, state all given values with units,
and specify what the student must find. Write in past or present tense — not imperative.
Do not give hints toward the solution method in the problem stem.]

Given:
- [Variable 1] = [value] [unit]
- [Variable 2] = [value] [unit]
- [Additional constraint or boundary condition if applicable]

Find:
[Single clear question. If multiple parts, label A, B, C.]

---

ANSWER CHOICES (if multiple choice)

(A) [value + unit] — [brief distractor rationale, internal only — omit from student view]
(B) [value + unit]
(C) [value + unit]
(D) [value + unit]

Correct answer: [letter]

---

SOLUTION

Step 1 — [Name the method or equation being applied]
[Show the governing equation before substituting values.]
[Equation]

Step 2 — [Substitute and solve]
[Show full substitution with units. Do not skip steps.]
[Equation with values]
[Result with units]

[Repeat for each step until final answer is reached.]

Final Answer: [value + unit] → Answer [letter]

---

COMMON MISTAKE
[Name the misconception or exam trap embedded in one of the distractors, and explain why students fall for it.]

⚠ SPEC FLAG (if applicable)
[Note any NCEES specification change post-2024 that affects this problem's content.]
```

## Mini-Quiz (2–4 problems on one topic)

Use the Standard Practice Problem template for each problem.
Add a header block before the first problem:

```
MINI-QUIZ: [TOPIC]
Exam Level: [FE / PE] | Discipline: [Discipline] | Difficulty: [Tier 1 / 2 / 3]
Problems: [N]

---
[Problem 1]
[Problem 2]
...
```

At the end of the mini-quiz, include a **Summary Table:**

```
| Problem | Concept Tested | Correct Answer | Difficulty |
|---------|---------------|---------------|------------|
| 1       | [concept]     | [letter]      | [tier]     |
| 2       | ...           | ...           | ...        |
```

## Distractor Design Rules

Distractors must be **plausible** — they are wrong answers a real student might reach by making a specific, nameable error. Do not use random values.

| Distractor type | How to generate it |
|---|---|
| Formula misremembering | Use a close-but-wrong version of the governing equation |
| Sign error | Flip a sign in the calculation |
| Wrong formula selection | Apply a similar formula that does not apply to these conditions |
| Missing conversion | Omit a required unit conversion |
| Stopped too early | Use the correct intermediate result, not the final answer |

Use no more than two distractor types per problem. Vary types across a mini-quiz.
