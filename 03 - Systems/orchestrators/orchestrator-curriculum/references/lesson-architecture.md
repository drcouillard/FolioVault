# Core Sequence

1. Objective
2. Prior knowledge activation
3. Concept introduction
4. Guided practice
5. Independent application
6. Assessment
7. Reflection / extension

# Progression Rule
Each lesson must build directly on prior mastery.

# Failure Modes
- concept leap without scaffolding
- no practice phase
- no assessment checkpoint
