# Hierarchy Rules

Order all layouts by:

1. primary focal element
2. secondary support content
3. action pathways
4. tertiary context

# Reading Flow
Default visual scan:
- top to bottom
- left to right
- strongest contrast first

# Priority Rule
The most important user action must be visually dominant.

# Failure Modes
- competing focal points
- equal visual weight everywhere
- unclear action emphasis
