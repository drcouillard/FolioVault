# Message Hierarchy

1. Core promise
2. Supporting proof
3. differentiators
4. action message

# Positioning Rule
Every communication must reinforce the core promise.

# Naming Rule
Names should align with identity principles and message hierarchy.

# Failure Modes
- multiple competing messages
- unclear value proposition
- naming disconnected from positioning
