# Brand Completeness Checklist

Use this file during Step 2 to validate whether any brand is ready for guide generation. Applies to any project type — personal brand, business, product, or client work.

## Required Before brand-style-guide

All items below must be confirmed complete and locked before routing to the guide generator.

### Identity Layer (from brand-identity-strategy)
- [ ] Brand name
- [ ] One-line description (what it does + who it's for)
- [ ] Target audience (specific, not generic)
- [ ] Brand personality (3-5 adjectives, confirmed)
- [ ] Positioning / differentiation statement
- [ ] Tagline (optional but recommended)

### Visual Layer (from visual-identity-system)
- [ ] Primary color palette (hex codes locked)
- [ ] Secondary color palette (hex codes locked)
- [ ] Primary typeface (name + usage rules)
- [ ] Secondary typeface (name + usage rules)
- [ ] Logo direction or logo rules (even if logo isn't final)
- [ ] Spacing and layout guidelines

### Voice Layer (from brand-voice-system)
- [ ] Tone description (how the brand sounds)
- [ ] Messaging pillars (2-4 core themes)
- [ ] Vocabulary guide (words to use / avoid)
- [ ] Copy standards (sentence rhythm, formality level)
- [ ] At least one sample product description or brand statement

## Prerequisites by Skill

### brand-identity-strategy
No prerequisites. This is always the starting point.

### visual-identity-system
Requires: Identity Layer complete

### brand-voice-system
Requires: Identity Layer complete

### brand-style-guide
Requires: All three layers complete

## How to Use This Checklist

When the user asks to build the brand guide or is partway through their brand, walk through this checklist. For each incomplete item, tell the user:
- What's missing
- Which skill fills that gap
- Why it's needed before moving forward

Do not skip items. Do not assume they're done without confirmation.
