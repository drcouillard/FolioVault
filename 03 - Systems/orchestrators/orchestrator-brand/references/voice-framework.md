# Voice Layers

## Core Voice
Stable personality traits
Example:
- precise
- authoritative
- accessible
- systems-oriented

## Tone
Situation-dependent variation
Example:
- instructional
- persuasive
- supportive
- technical

# Rule
Voice remains stable.
Tone adapts by context.

# Failure Modes
- changing personality across contexts
- tone mismatch with audience
