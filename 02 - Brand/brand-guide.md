## SECTION 01 — Brand Overview

### One-Line Description

Folio Interactive builds adaptive educational software that meets learners where they are, challenges them to think deeply, and equips educators with tools that flex to any classroom.

### Mission Statement

To make rigorous, personalized learning accessible — software that adapts to the learner, illuminates the path forward, and builds the confidence to keep going.

### Value Proposition

Folio Interactive doesn't just deliver content — it responds to how each user thinks, learns, and struggles, then adjusts in real time to accelerate mastery without leaving anyone behind.

### Brand Archetype

| | |
| --- | --- |
| **Primary: The Sage** | **Secondary: The Caregiver** |
| Driven by knowledge and truth. Calm authority, intellectual depth, earns trust through competence. | Patient, attuned to struggle, present during difficulty. Prevents the Sage from feeling cold. |

### Brand Personality

In priority order: Adaptive · Purposeful · Illuminating · Principled · Empowering

### Positioning Statement

For K-12 learners and educators who need more than passive instruction, Folio Interactive is the adaptive learning platform that teaches students how to think — not just what to know — because mastery is built through doing, not watching.

### Target Audiences

| The Independent Learner | The Classroom Educator | The Engaged Parent / College Learner |
| --- | --- | --- |
| Curious, self-motivated, K-12. Wants to go deeper or faster than the classroom allows. | K-12 teacher or administrator. Values credibility, ease of deployment, measurable outcomes. | Parent seeking enrichment or college student needing subject depth beyond lecture. |

The Folio Interactive mark is built from four node points connected by lines that form the silhouette of an open book. The network structure literally constructs the book shape — referencing modular learning, mind mapping, and adaptive architecture simultaneously.

## SECTION 04 — Typography

### Type System Overview

Lora (serif) carries editorial authority at heading scale. Barlow (sans-serif) delivers legibility and warmth at UI and body scale. Both are available via Google Fonts at no cost.

### Type Roles

| Role | Font | Size / Weight | Usage |
| --- | --- | --- | --- |
| Display / H1 | Lora | 32px / 600 | Hero text, module titles, major headings |
| H2 | Lora | 20px / 500 | Section headers, lesson titles, card headings |
| H2 / Subheading | Barlow | 16px / 400, 1.7 lh | Lesson content, instructions, explanations |
| Body | Barlow | 14px / 500–600 | Navigation, buttons, labels, form fields |
| UI Labels / Nav<br>Captions / Meta | Barlow | 12px / 400 | Timestamps, module metadata, footnotes |

### Usage Rules

- Lora is used for headings only — never for body copy or UI labels.
- Barlow replaces Helvetica Neue or Arial in all digital contexts. Helvetica Neue is a print font and degrades at small screen sizes.
- Minimum body size: **16px**. Minimum caption size: **12px**. Never go below 12px in any UI context.
- Two weights only in Barlow: **400** (regular) and **500–600** (medium/semibold). Avoid 700+ — too heavy against the palette.
- Line height for body copy: **1.7**. Headings: **1.2–1.35**.

                    Formal                                                    Humble
                    Serious                                                   Reserved

### Tone Description

Folio Interactive speaks like a teacher who genuinely loves their subject — one who explains a concept clearly, waits to see if it landed, and finds a better angle if it didn't. The tone is warm but never soft. Precise but never cold. It meets students where they are without talking down to them, and it treats struggle as a natural part of the process rather than a failure to fix. When something is hard, we say so. When something clicks, we acknowledge it. We are always on the student's side.

### Voice References

Bill Nye · Neil deGrasse Tyson · Michael Stevens (VSauce)  
Enthusiastic, grounded, intellectually humble, patient, never dumbed-down.

### Named Component: The Big Idea Callback

The phrase **"What's the big idea here?"** is a core recurring element used verbatim across two distinct contexts in every module:

| | Passive — Mid-module | Active — EIB Prompt |
| --- | --- | --- |
| **Role** | Rhetorical. Appears after fundamentals are introduced, before the analogy/metaphor section. Signals the cognitive reset from detail to pattern. The system answers it through a comparative visual and compressed restatement. No student response required. | Inquiry-facing. Appears at the Explain It Back (EIB) assessment stage. The student is now expected to answer it. Manifestations: open-response, drag-and-drop concept map, verbal explanation, or peer-simulation. The answer is the mastery evidence. |

**Module arc:** Fundamentals → "What's the big idea here?" (we show you) → Analogy → Practice → "What's the big idea here?" (you show us)

## SECTION 06 — Messaging Pillars

### You're seen here.

Every learner is different. The software adapts — it doesn't make the student adapt to it.

*"Folio adjusts to how you learn, not the other way around."*

### Mastery is built, not given.

Understanding comes through doing, not watching. Every interaction is practice, not performance.

*"You don't just read about forces. You apply them, test them, and explain them back."*

### Struggle is part of the process.

Difficulty signals learning in progress. The platform treats errors as data, not failures.

*"Getting it wrong the first time is how you find out what you actually know."*

### Curiosity compounds.

One concept connects to another. The goal is to make students want to go further.

*"This module ends here. The question it leaves you with doesn't."*

### Think about your thinking.

Metacognition is a skill. Students learn not just the subject, but how they learn it.

*"Could you explain this to someone who's never heard of it? Try."*

## SECTION 07 — Copy Rules

### Vocabulary

| Use | Avoid |
| --- | --- |
| build, explore, practice, notice, connect, demonstrate, try, mastery, pattern, evidence, reflect, apply, strengthen, understand | leverage, unlock, crush it, easy, simply, just, fail, wrong, optimize, seamless, robust, innovative |

### Copy Rules by Context

| Context | Rules |
| --- | --- |
| Onboarding | Welcome without fanfare. Lead with what the student will do, not what the platform does. Max 2 sentences per screen. Never promise "easy." |
| Encouragement during struggle | Acknowledge difficulty honestly. Redirect to pattern or strategy, not the answer. Never say "almost!" or "so close!" — say what they got right and what to look at next. |
| Mastery confirmation | Mark the moment specifically. Name what was demonstrated. One exclamation point maximum. Connect forward — what does this unlock? |
| Error / wrong answer | Never say "wrong" or "incorrect." Say what the answer reveals. Redirect to reasoning, not score. Neutral, not cheerful — false positivity erodes trust. |
| Instructor UI | Direct and efficient. Lead with action or data. Plain language over edtech jargon. Respect expertise — don't over-explain. |
| Marketing / website | Lead with the differentiator: adaptive, metacognitive, VAK. Avoid generic claims. Make a specific claim and back it with a mechanism. |

### Sentence Rhythm

- Default pattern: Short setup → medium explanation → short landing. Vary deliberately.
- Em dashes: Yes — used to extend a thought naturally.
- Exclamation points: One per screen maximum. Reserved for genuine milestone moments only.
- Lead with: What the student needs to do or notice — not what the system is doing.
- Contractions: Yes — "you're", "it's", "don't" keep the voice human without going casual.
- Fragments: Acceptable sparingly for emphasis. ("That's mastery.") Not as a default pattern.

## SECTION 08 — Do's & Don'ts

### Phrase Guidance

| Prefer | Avoid ("Not this") | Why |
| --- | --- | --- |
| Let's look at what happened | You got it wrong | Redirects to learning, not judgment. Teaches the thinking, not just the answer. |
| Notice what these have in common | The answer is... | Specific validation over generic praise. Connects rather than restarts. Tests real mastery, not self-assessment. |
| You demonstrated mastery of... | Great job! You passed! | Constructive redirection without deflation. Evidence over empty encouragement. |
| This builds on what you know | Before we begin... | Honest framing protects student confidence. Metacognitive prompt over rote recall. |
| Could you explain this to someone else? | Do you understand? | Specific mechanism over marketing blur. |
| Try a different approach | That's not right, try again | |
| Here's what the data shows | You're doing great! | |
| This is a tricky one | This should be easy | |
| What would you tell a classmate? | Summarize the lesson | |
| Adaptive learning | Personalized learning journey | |

### Anti-Positioning — What Folio Interactive Is Not

- Gamified entertainment masquerading as education
- A passive video lecture platform
- Quirky, casual, or trend-chasing in tone or design
- A one-size curriculum with rigid pacing
- A replacement for the teacher — a force multiplier for them
- Generic in its claims ("engaging," "powerful," "seamless")
