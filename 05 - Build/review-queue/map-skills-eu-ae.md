# Map Skills — Backward Design Foundation

This document is the backward design gate for the Map Skills module. No content,
questions, or assessments may be drafted until this document has been verified by
a named educator and advanced to Beta status.

---

## Enduring Understanding

**Maps are not pictures of the world — they are designed tools built to answer specific
geographic questions.** Every map encodes choices: what to include, what to omit, how
to represent location, what each symbol means. A skilled map reader knows what question
a map was built to answer, and uses the map's tools — coordinate systems, legends, and
type conventions — to extract precise answers.

> **The test of endurance:** A student who truly holds this understanding will, one year
> from now, encounter an unfamiliar map — a census map, a weather map, a trail map —
> and ask first: *what question was this built to answer?* That instinct is the EU.
> Knowing how to read latitude coordinates is a skill. Knowing that every map was
> built to answer a question is an understanding.

## Acceptable Evidence

Mastery is demonstrated when a student can do all five of the following on maps
they have not seen during instruction (transfer context required):

### Evidence 1 — Map Purpose Identification
Given an unfamiliar map, the student:
- Names the geographic question the map was designed to answer
- Identifies one thing the map cannot tell them, and explains why the map's design
  makes that information unavailable

*Knowledge type: Conceptual-Principle. Bloom target: Analyze.*

### Evidence 2 — Coordinate Precision
Given an unfamiliar world or regional map with a coordinate grid, the student:
- Locates a named place to within one degree of latitude and longitude
- States what those coordinates mean in real-world terms (hemisphere, approximate
  distance from equator/prime meridian)

*Knowledge type: Procedural + Declarative. Bloom target: Apply.*

### Evidence 3 — Legend Extraction
Given an unfamiliar map with a legend they have not seen before, the student:
- Reads the legend accurately
- Uses it to answer a specific geographic question about a named place on the map

*Knowledge type: Procedural. Bloom target: Apply.*

### Evidence 4 — Map Type Discrimination
Given two map types showing the same region (e.g., political and climate), the student:
- Names each map type
- Explains what geographic question each was built to answer
- Identifies which map would answer a given question, and why the other would not

*Knowledge type: Conceptual-Principle + Declarative. Bloom target: Analyze.*

### Evidence 5 — Transfer (Integration)
Given a geographic question the student has not seen in instruction and a set of
available map types, the student:
- Selects the appropriate map type
- Locates the relevant area using coordinates
- Uses the legend to extract the answer
- States one limitation of the map they chose

*All four skills applied together. Bloom target: Evaluate.*

> **Mastery rule:** All five evidence items must be demonstrated. Correctness on
> familiar maps does not qualify. Evidence 5 (transfer) is the minimum gate for
> advancing to Gold status — it cannot be substituted.

## Educator Verification Scope

Educator verification has two distinct jobs. Both must be completed before Beta status
is awarded. They may be done by the same person or split across two reviewers.

### Job 1 — Content Accuracy
The educator confirms that factual content is correct and appropriately scoped for
the grade band. This includes:

- **True/false and factual questions:** Is every stated fact accurate? (e.g., "The
  equator is at 0° latitude" — correct. "The prime meridian runs through Paris" —
  incorrect, flag it.)
- **Map type definitions:** Are the definitions of political, climate, physical, and
  thematic maps accurate and grade-appropriate?
- **Coordinate system content:** Is the explanation of latitude, longitude, hemispheres,
  and the coordinate grid factually sound?
- **Legend reading content:** Are the legend examples used in instruction accurate
  representations of real map conventions?

The educator does not need to evaluate pedagogy or question format — only factual
accuracy and grade-level appropriateness.

### Job 2 — Assessment Format Soundness
The educator confirms that the assessment designs will produce reliable, scoreable
evidence. This includes:

- **Gradability:** Can a teacher score each question consistently? Is the correct
  answer unambiguous?
- **Format fit:** Does the chosen question format (MCQ, drag-and-drop, short response)
  actually surface the evidence it claims to measure?
- **Distractor validity:** For multiple choice questions, are the wrong answers
  plausible misconceptions — not trick questions or obviously wrong choices?
- **Transfer item validity:** Is the transfer assessment item (Evidence 5) genuinely
  novel — not just a reworded version of a practice problem?

The educator does not need to evaluate instructional design theory — only whether
the assessment is fair, scoreable, and measures what it says it measures.
